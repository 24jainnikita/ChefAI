# # ChefAI — AI-Powered Ingredient & Meal Discovery Platform 🍲

Mood-aware AI recipe discovery platform built with HTML, CSS, JavaScript, and Spoonacular API.

ChefAI helps users discover recipes based on:
- available ingredients
- mood
- cuisine preference
- cooking time
- dietary preferences

Designed with a warm, modern UI focused on reducing food waste and simplifying meal planning.

## 🧠 Project Vision

Most recipe apps assume users already know what they want to cook.

ChefAI solves the opposite problem:
> “I only have a few ingredients and no idea what to make.”

The project combines ingredient-based search with mood-driven discovery to create a more natural cooking experience.
